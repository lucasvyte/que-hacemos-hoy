# ¿Qué hacemos hoy?

Lista compartida de actividades, lugares para comer y para visitar. App web instalable (PWA) con Firebase (Google Sign-In + Firestore), mapa con OpenStreetMap/Leaflet y "Compartir" desde Instagram en Android.

- Versión: ver `VERSION` en `app.js` (formato mayor.menor.corrección).
- Reglas de Firestore: `firestore.rules` (se pegan en la consola de Firebase).
- Al subir una versión nueva, cambiar también `CACHE` en `sw.js`.
